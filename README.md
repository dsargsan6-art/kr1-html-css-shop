# Учебный frontend-проект

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта
- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии
- HTML;
- CSS;
- Git;
- GitHub.

## Контрольная работа №1
Тема: «HTML и CSS: разработка многостраничного сайта».
Разрабатывается многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг: 5 страниц, семантическая разметка, единая навигация и якоря, карточки, таблица, форма и модальное окно, внешний CSS с переменными и состояниями, Flexbox и Grid, позиционирование, публикация через GitHub Pages.
